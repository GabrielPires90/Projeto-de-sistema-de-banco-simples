# Sistema de Banco Simples

Este projeto é um sistema de banco simples desenvolvido em **Python**, com foco na aplicação de conceitos de **Programação Orientada a Objetos (POO)**.  
Ele simula operações básicas de um banco, como criação de contas, depósitos, saques e consulta de saldo.

O projeto foi desenvolvido com fins **educacionais**, como forma de praticar lógica de programação e organização de código.

---

## Objetivo do Projeto

- Praticar conceitos fundamentais de **POO**
- Trabalhar com **classes, métodos e atributos**
- Simular regras básicas de um sistema bancário
- Melhorar a organização e legibilidade do código

---

## Tecnologias Utilizadas

- **Python 3**
- Programação Orientada a Objetos (POO)

---

## Funcionalidades

- Criar conta bancária
- Depositar valores
- Sacar valores
- Consultar saldo
- Validação básica de operações
